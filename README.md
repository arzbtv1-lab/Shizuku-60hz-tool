# Shizuku-60hz-tool

เครื่องมือสำหรับจัดการและควบคุมการตั้งค่าอัตรารีเฟรชหน้าจอ 60Hz และใช้งานร่วมกับสิทธิ์ Shizuku บนระบบ Android

## คุณสมบัติเด่น
* ตั้งค่าและล็อกอัตรารีเฟรชหน้าจอเป็น 60Hz เพื่อประหยัดพลังงาน
* รองรับการทำงานร่วมกับ Shizuku สำหรับคำสั่งระดับสูงโดยไม่ต้อง Root เครื่อง
* หน้าตาอินเทอร์เฟซใช้งานง่าย

## วิธีการใช้งาน
1. ติดตั้งแอปพลิเคชันและเปิดใช้งาน Shizuku
2. ตั้งค่าคำสั่งปรับความถี่หน้าจอผ่านระบบ
